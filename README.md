# ✈️ Flight Delay Predictor

A machine learning application that predicts whether a flight will arrive **15 minutes or more late** using historical US Bureau of Transportation Statistics (BTS) flight data and LightGBM.

## 🚀 Features

- Predict flight arrival delays before departure
- Uses BTS On-Time Performance dataset
- LightGBM machine learning model
- Weather-aware feature engineering
- Streamlit web interface
- Automated testing using Pytest
- Efficient handling of large flight datasets

## 📊 Dataset

**Source:**  
US Bureau of Transportation Statistics (BTS) Reporting Carrier On-Time Performance Dataset

### Important Columns Used

- Month
- DayOfWeek
- Reporting_Airline
- Origin
- Dest
- CRSDepTime
- Distance
- Cancelled
- ArrDel15

### Target Variable

- `ArrDel15 = 1` → Arrival delayed by **15+ minutes**
- `ArrDel15 = 0` → On-time arrival

---

## ⚠️ Data Leakage Prevention

The model intentionally excludes information unavailable before departure.

### Dropped Columns

- DepTime
- DepDelay
- ArrDelay
- WeatherDelay
- CarrierDelay
- NASDelay
- LateAircraftDelay

### Features Used

- Month
- DayOfWeek
- Reporting_Airline
- Origin
- Dest
- Scheduled Departure Time (`CRSDepTime`)
- Distance
- Weather Features
  - Temperature
  - Wind Speed
  - Precipitation

## 🔧 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/flight-delay-predictor.git
```

Move into the project:

```bash
cd flight-delay-predictor
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

### Windows

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🧪 Run Tests

```bash
pytest -v
```

Expected output:

```text
4 passed
```

---

## 🏋️ Train the Model

```bash
python train.py
```

This generates:

```text
models/lgbm_flight_model.pkl
```

---

## 🌐 Run the Web Application

Start Streamlit:

```bash
streamlit run app.py
```

Then open the local URL generated by Streamlit in your browser.
